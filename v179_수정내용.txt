류현상 키우기 v179 수정 내용

1. 실시간 랭킹
- 엔딩 탭 완전 제거
- 엔딩 달성명/엔딩 수집 수/클리어 일수를 랭킹 서버로 새로 전송하지 않음
- 랭킹은 재산 / 팬 / 외모 / 종합 4개만 표시
- v178 DB 설정을 이미 했다면 추가 SQL 실행 불필요

2. 테트리스 미니게임
- 전용 모달 레이아웃 적용
- 화면 높이에 맞춰 게임판이 자동 축소
- 모바일에서도 스크롤 없이 스타트 버튼, 게임판, 점수, 조작 버튼이 한 화면에 보이도록 조정

3. 엔딩 컬렉션
- 해금 여부와 관계없이 전체 엔딩 슬롯 표시
- 미해금 엔딩: 이미지 강한 블러 + 잠금 표시, 제목은 '???'
- 해금된 엔딩: 실제 제목과 이미지 표시, 다시 보기 가능
- 미해금 슬롯을 눌러도 엔딩 이름은 공개되지 않음
