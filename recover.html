🚑 류현상 키우기 긴급 저장 복구센터

1일차 초기화 사고용 복구 페이지입니다. 같은 GitHub Pages 주소에서 실행해야 기존 브라우저 저장소와 익명 Supabase 계정을 읽을 수 있습니다.

중요: 먼저 이 페이지에서 복구를 시도하고, 앱 삭제·브라우저 데이터 삭제·사이트 데이터 삭제는 하지 마세요. 삭제된 자동저장 자체는 브라우저에서 되살릴 수 없지만, 남아 있는 수동 슬롯/백업/구버전 저장 또는 온라인 랭킹·커뮤니티 기록으로 최대한 복원합니다.

1. 기기 안에 남은 저장 전체 검색

아직 검색하지 않았습니다.

2. 온라인 기록으로 핵심 진행 복구

랭킹 기록과 본인이 과거에 작성한 커뮤니티 글의 [게임 기록]을 확인합니다. 이 방식은 날짜·돈·팬·인지도·보컬·작곡·연기·외모 같은 핵심 수치는 복구할 수 있지만, 서버에 저장되지 않았던 집/의상/장비/세부 이벤트는 정확히 복구하지 못할 수 있습니다.

아직 검색하지 않았습니다.

3. 복구 후

복구를 누르면 현재 1일차 자동저장은 먼저 별도 비상 백업 키로 보존한 뒤, 복구된 데이터를 ryuGameAuto에 넣습니다.
이 페이지는 자동저장을 삭제하지 않습니다. 복구 실행 전의 현재 자동저장도 별도 키로 남깁니다. 복구센터 파일은 문제 해결 후 GitHub에서 삭제해도 됩니다.
