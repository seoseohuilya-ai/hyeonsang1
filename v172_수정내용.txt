류현상 키우기 v172 · 온라인 3인 고스톱 화면 수정
================================================

기준 버전
- ryu-hyunsang-game-v171-ai-fullscreen.zip 기반

수정 내용
1. 온라인 2인 맞고 / 3인 고스톱 실제 게임 진행 화면을 전체화면으로 변경
   - 후라보노 AI 맞고와 같은 100vw × 100dvh 전체화면 방식
   - 게임 진행 중 기존 모달 상단 제목/닫기 영역 숨김
   - 게임판 안의 [기권] 버튼은 그대로 유지

2. 온라인 3인 고스톱 상대방 먹은 패 표시 수정
   - 기존 모바일 CSS에서 상대 먹은 패 실제 이미지가 display:none 처리되던 문제 수정
   - 상대 2명의 광 / 열끗 / 띠 / 피 실제 카드 이미지를 다시 표시
   - 상대 손패는 기존대로 뒷면으로 유지

3. iPhone 세로 화면 내 먹은 패 배치 수정
   - 내 먹은 패 영역을 화면 전체 폭(grid-column:1/-1)으로 확장
   - 왼쪽 작은 영역에 쏠리던 현상 수정
   - 광 / 열끗 / 띠 / 피를 2×2 영역으로 배치
   - 실제 화투 이미지가 보이도록 카드 크기와 간격 조정

4. 한 화면 표시 최적화
   - 상대 2명은 가로 2칸 유지
   - 중앙 바닥패 영역 높이 축소
   - 내 손패와 먹은패를 화면 하단 전체 폭으로 정렬
   - iPhone safe-area 여백 대응

5. PWA 캐시 갱신
   - service-worker 캐시 이름을 ryu-hyunsang-v172-online-gostop-fullscreen 으로 갱신

GitHub에 최소 교체할 파일
- matgo.css
- service-worker.js

전체 ZIP을 덮어써도 됩니다.
Supabase SQL 변경은 필요 없습니다.

6. 최종 검증 보정
   - index.html / game.js / service-worker.js의 캐시 버전 문자열을 v172-online-gostop-fullscreen으로 통일
